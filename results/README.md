# Recorded IBEM experiments

- `ibem50-20261025/`: the four-model comparison, interactive viewer, original
  sample images, raw model outputs, metrics, provenance, and validation record.
- `ibem10-20261025-cpu-ne/`: the original ten-page CPU + ANE evaluation and viewer.
- `ibem10-20261025-all/` and `ibem10-20261025-cpu/`: same-model compute-mode checks.

To open the latest comparison, serve this directory's 50-page bundle:

```sh
python3.13 -m http.server 8767 --bind 127.0.0.1 --directory results/ibem50-20261025
```

Then visit <http://127.0.0.1:8767>. The viewer uses local images and data and
supports PNG export. See [evaluation instructions](../evaluation/README.md) for
reproduction and the [comparison report](ibem50-20261025/REPORT.md) for methods.

## Dataset attribution

The included page images and math annotations are from
[`deepcopy/IBEM-v1-math-detection`](https://huggingface.co/datasets/deepcopy/IBEM-v1-math-detection),
revision `4f82284a793f020a9235efe26dbd6ed5d733a022`. The source dataset card states
CC BY 4.0; a copy is retained in [DATASET_CARD.md](DATASET_CARD.md). Original image
bytes are preserved. Predictions, overlays and review sheets are generated by
this experiment and are identified separately in each result directory.

Original dataset: Anitei, D., Sánchez, J. A., & Benedí, J. M. (2023),
*The IBEM Dataset: a large printed scientific image dataset for indexing and
searching mathematical expressions (1.0)*, Zenodo,
<https://doi.org/10.5281/zenodo.7963703>.

The samples are a deterministic convenience selection from distinct documents,
not a random or full-test-set benchmark. The experiment compares the recorded
backend configurations; its results do not establish general model rankings.
